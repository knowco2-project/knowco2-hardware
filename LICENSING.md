# Licensing map

KnowCO2 uses separate licenses for hardware source, documentation, and third-party components. This map is authoritative for the repository paths listed below.

| Material | Paths | License |
|---|---|---|
| Original KnowCO2 hardware source | `enclosure/step/**`, `enclosure/stl/**`, `enclosure/images/**`, `bom/bom.csv` | CERN-OHL-S-2.0 |
| KnowCO2 documentation | `README.md`, `CHANGES.md`, `RELEASING.md`, `LICENSING.md`, `bom/README.md`, `docs/**`, `enclosure/README.md` | CC-BY-SA-4.0 |
| Third-party modules and linked reference designs | Not copied into this repository | Their respective upstream licenses |

The complete CERN-OHL-S-2.0 text is in [`LICENSE`](LICENSE) and [`LICENSES/CERN-OHL-S-2.0.txt`](LICENSES/CERN-OHL-S-2.0.txt). The project-specific notice, Covered Source paths, warranty disclaimer, and Source Location are in [`LICENSE-HARDWARE`](LICENSE-HARDWARE).

The complete CC-BY-SA-4.0 text is in [`LICENSES/CC-BY-SA-4.0.txt`](LICENSES/CC-BY-SA-4.0.txt).

## Source Location

The Source Location is:

https://github.com/knowco2-project/knowco2-hardware

Anyone producing hardware from the Covered Source must visibly and securely display that Source Location on the Product, its packaging, or accompanying documentation, as specified in `LICENSE-HARDWARE`.

## Modifications

Modified Covered Source must retain applicable notices and include a dated, brief description of the modifications. Use `CHANGES.md` for repository-wide changes or an equivalent modification record in a redistributed design package.
